# Prototipo UI-3 de identidad y acceso

Este directorio es una propuesta visual navegable para revisión del director.

**PROTOTIPO DE REVISIÓN — NO FORMA PARTE DEL PRODUCTO**

- No contiene backend, API, base de datos, sesiones, cookies ni persistencia.
- Los estados se revisan con `?state=default|loading|error|success|expired`.
- Los formularios bloquean el submit y no registran valores.
- Usa únicamente el logotipo existente mediante una ruta relativa.
- El copy y la composición son provisionales y requieren aprobación expresa.

Abrir `index.html` para navegar las cinco superficies.
